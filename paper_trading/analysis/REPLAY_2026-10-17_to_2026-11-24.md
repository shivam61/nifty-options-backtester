## Method

Same as the 2026-05-15 to 2026-10-16 replay, with these changes:

- **Strategy rule:** `select_weekly_strategy_name` (IC if VIX 12–22 and |5-day Nifty return| < 2%, otherwise PCS). Owner decision on 2026-11-24. The journal's older rule ("PCS if VIX ≤ 16, else IC") is not used here. See deviation below.
- **Decision timing:** entry is decided at 11:30 using the previous session's data. Exits are then checked on the 15:15 close of each later session. The position as it stands at 11:30 decides whether a new entry is possible.
- **Entry gap:** mid-session spot vs previous close, which is the journal's own convention (RP-001 note: 23,549.30 / 23,643.50 − 1 = −0.40%).
- **Exit gap:** the exit session's close-to-close move, applied to the executable fill.
- **Fill penalties:** `ConservativeFillModel` with the slippage scale set separately for entry (×1.125) and exit (×1.5). Both were fitted to the 19 journalled trades (see Validation).
- **Costs:** brokerage ₹500 per trade. Statutory charges are not included (same as before).
- **Code:** `scripts/replay_asof_weekly.py` (dry run by default; `--write` appends to the tracker CSVs; refuses to run unless the journal ends on the day before `--start`).

## Deviations and open questions for the owner

1. **Strategy rule.** The journal's Phase-1 rule ("PCS if VIX ≤ 16, else IC") differs from the code rule that `signal-combined` prints (`select_weekly_strategy_name`). This replay uses the code rule. The journal's operator rule and the code need to agree before live use.
2. **New skip code `IC_DECLINED`** is not in the RESTART section (c) table. It covers an IC gate decline, which the table did not anticipate.
3. **Stop overshoot.** RP-020 closed at about 1.7× its credit (exit ₹70.99 vs credit ₹26.65) on the daily close, the same pattern as RP-006 and RP-008 in the earlier replay. Daily-close stops can fill well beyond the 100% threshold.
4. **Penalty calibration.** The entry (×1.125) and exit (×1.5) slippage scales were fitted to the journal's fills. They are not independently justified and should be revisited once real broker fills exist.

## Limits

- Every premium is Black-Scholes with calibrated fill penalties, not a quote. Real fills may differ, especially on stop days when spreads widen.
- Stops, breaches and targets are checked on daily closes, not intraday. Intraday breaches could exit earlier and at worse prices.
- The 2026-11-08 muhurat session is not modelled.
- Results are not evidence of an edge. The chain backtest's pre-registered verdict remains NOT SUPPORTED (see `BACKTEST_CHANGELOG.md`, 2026-10-21).
